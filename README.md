# 📊 DataCo Supply Chain Analytics

An end-to-end Data Analytics and Business Intelligence project focused on analyzing supply chain operations, sales performance, profitability, and delivery efficiency using Python, SQL, Excel, and Power BI.

## 🎯 Project Overview

This project uses the DataCo SMART Supply Chain dataset to identify business trends, analyze operational performance, and generate actionable insights.

The project follows a complete data analytics workflow, from raw data inspection and cleaning to SQL analysis and interactive Power BI dashboards.

## 🛠️ Tools & Technologies

- **Python:** Data Cleaning and Exploratory Data Analysis
- **Pandas:** Data Manipulation
- **Matplotlib & Seaborn:** Data Visualization
- **MySQL:** Business Analysis and SQL Queries
- **Power BI:** Interactive Dashboards
- **Excel:** Dataset Preparation

## 📂 Project Structure

- `01_Data_Sample` – Raw dataset sample
- `02_Data_Cleaned_Sample` – Cleaned dataset sample
- `03_Python` – Python data cleaning and EDA
- `04_Visualizations` – Exploratory data visualizations
- `05_SQL` – SQL business analysis queries
- `06_PowerBI` – Interactive Power BI dashboard and screenshots
- `07_Report` – Detailed project report

## 📈 Key Analysis Areas

- Sales and revenue performance
- Profitability across markets and product categories
- Shipping mode performance
- Late delivery risk analysis
- Customer revenue contribution
- Monthly profit trends
- Supply chain operational efficiency

## 📊 Power BI Dashboard

The project includes three interactive dashboard pages:

1. **Executive Overview** – Overall business performance, revenue, profit, and order metrics.
2. **Shipping Performance** – Shipping efficiency, delivery delays, and shipping mode analysis.
3. **Root Cause Drill-Down** – Investigation of delivery risks across markets and shipping modes.

## 🔍 Key Findings

- Overall late delivery rate: 54.83%.
- Average shipping delay: 0.57 days.
- Total revenue: $36.78M.
- Total profit: $3.97M.
- Shipping performance varies across shipping modes and markets.

## 💡 Business Recommendations

- Investigate high-risk shipping modes.
- Improve delivery planning and reduce shipping delays.
- Monitor markets with higher delivery risks.
- Focus on retaining high-value customers.
- Track profitability and delivery KPIs through interactive dashboards.

## 📁 Dataset

Dataset: DataCo SMART Supply Chain for Big Data Analysis.

The complete dataset was used locally. This repository contains representative raw and cleaned data samples due to repository size considerations.
